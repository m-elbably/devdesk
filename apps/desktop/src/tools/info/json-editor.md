# JSON Editor

A tree/text editor for JSON, with formatting and validation as you type.

Paste or edit JSON in the editor pane; invalid JSON is flagged inline rather than silently dropped. On a valid document, the tool re-serializes with 2-space indentation, so pasting in minified JSON is also how you pretty-print it.

## Tip

Use the tree view to collapse deeply nested objects and arrays while you look for a specific key — it's usually faster than scrolling raw text.
